# Leo (`@leomatchbot`) — профиль и лента, для adoption в code-davinci

Источник: живой прогон в Telegram Web `https://web.telegram.org/a/#1234060895` 15.08.2026.
Premium не разбирался.

Leo в продукте называется «Дайвинчик». ~13.8M monthly users. Команды вне меню: `/start`, `/myprofile`, `/language`, `/complaint`.

---

## 1. Модель управления

Два разных языка кнопок. Их нельзя смешивать.

**Меню (дом / анкета / онбординг-выбор)** — reply keyboard с **человекочитаемыми подписями** или цифрами. Легенда дублируется текстом в сообщении:

```
1. Смотреть анкеты.
2. Моя анкета.
3. Я больше не хочу никого искать.
***
4. …
```

На доме физические кнопки: `1` `2` `3` `4`.
На экране анкеты: `1` `2` `3` `4` `5`.

**Лента** — не цифры, а эмодзи в один ряд: `❤️` `👎` `💤` `🚨`.

**Критично:** бот принимает только **точный текст кнопки**, не видимую подпись и не близкий синоним.

| Что видно / что набрали | Что бот реально ждёт | Результат ошибки |
|---|---|---|
| «Девушек» | `Девушки` | `Нет такого варианта ответа` |
| «Это все» | `Это все, сохранить фото` | снова просит фото |
| `💤` во время промо-сообщения | ответ на промо, не свайп | `Нет такого варианта ответа` |

`/start` в середине шага **сбрасывает шаг** и возвращает на экран анкеты, не продолжая онбординг.

Для DaVinci: если копируем numbered keyboard + легенду в сообщении — парсить только exact button text; синонимы («Девушек» vs «Девушки») ломают флоу. Сейчас в `keyboards.ts` как раз куча алиасов — это антипаттерн Leo.

## 2. Формирование профиля (онбординг / «заполнить заново»)

Вход: анкета → `2` (`Заполнить анкету заново`). Старый профиль сразу уходит в перезапись, без «ты уверен?».

Порядок шагов (пройден целиком):

| # | Промпт | Ввод | Клавиатура |
|---|---|---|---|
| 1 | `Сколько тебе лет?` + предупреждение, что недостоверный возраст могут ограничить | число (`19`) | нет спец. кнопок |
| 2 | `Теперь определимся с полом` | `Я парень` / `Я девушка` | 2 кнопки |
| 3 | `Кого показывать?` | `Девушки` / `Парни` / `Все равно` | 3 кнопки |
| 4 | `Из какого ты города?` | город текстом **или** геолокация | `Отправить местоположение` |
| 5 | `Как мне тебя называть?` | свободный текст | — |
| 6 | `Расскажи о себе и кого хочешь найти, чем предлагаешь заняться. Это поможет лучше подобрать тебе компанию.` | свободный текст, обязательный | — |
| 7 | `Пришли своё фото или запиши видео(до 15 сек).` + «лицо собирает больше лайков» + «чужие фото и картинки из интернета не подходят» | фото или видео | — |
| 7b | `Фото добавлено – 1 из 3. Еще одно?` | ещё фото **или** `Это все, сохранить фото` | `Это все` |
| 8 | Превью: `Так выглядит твоя анкета:` + фото + caption, затем `Все верно?` | `Да` или `Изменить анкету` | `Да` / `Изменить анкету` |

После `Да` — **сразу первая карточка ленты**, без домашнего меню.

### Что важно в шагах

- Возраст спрашивают **первым**, не имя. Год рождения не просят — только возраст. Предупреждение про фейк-возраст, не жёсткий 18+ экран (18+ не проверяли).
- Пол — бинарный, нужен для фильтра «кого показывать». На карточке пол **не пишется**.
- «Кого показывать» — dating-фильтр. В PRD DaVinci этого нет и не должно появиться как dating-mode.
- Город: текст или live-location. Самара принялась как есть, без списка городов и без уточнения.
- Имя — как обращаться, не Telegram username.
- Био обязательное. Формулировка задаёт три темы: о себе / кого ищешь / чем заняться. В edit тот же смысл короче: `Расскажи о себе, кого хочешь найти, чем предлагаешь заняться`.
- Фото — главный объект анкеты. До 3 штук. Видео до 15 сек вместо фото. После первого — «ещё одно?» а не сразу превью.
- Превью = ровно то, что увидят другие: фото + одна строка caption. Отдельного «подтверди» с кодом/полями нет.
- `Изменить анкету` на превью не нажимали — неясно, это полный рестарт или точечный edit.

### Сравнение с текущим DaVinci

| | Leo | code-davinci сейчас |
|---|---|---|
| Порядок | возраст → пол → фильтр → город → имя → био → фото → превью | язык → имя → год → пол → био → локация → сниппеты → превью |
| Главный контент карточки | фото/видео | сниппет кода |
| Фото в ленте | да, сразу | нет, только после мэтча |
| Био | обязательное | optional, skip |
| Сколько медиа | 1–3 фото или видео 15с | 1 photo_file_id, скрыто |
| Фильтр «кого показать» | да | нет, и не нужен по PRD |
| После confirm | сразу лента | дом / своя карточка |
| `/start` | экран своей анкеты | дом |

## 3. Редактирование профиля

`/start` и `/myprofile` / дом `2` открывают **один и тот же экран анкеты**:

1. `Так выглядит твоя анкета:`
2. своё фото + caption как в ленте
3. меню:

```
1. Смотреть анкеты.
2. Заполнить анкету заново.
3. Изменить фото/видео.
4. Изменить текст анкеты.
***
5. …
```

Клавиатура: `1` `2` `3` `4` `5`.

### Точечный edit

**Фото (`3`)** — тот же промпт, что в онбординге. Ждёт медиа. `/start` отменяет, профиль не меняется.

**Текст (`4`)** — только био, одним сообщением. Имя/возраст/город отсюда не меняются. `/start` отменяет.

**Заново (`2`)** — полный онбординг, без подтверждения потери старых данных.

Имя, возраст, город, пол, «кого показывать» **не имеют отдельных пунктов** в обычном edit. Чтобы сменить их — только «заполнить заново».

### Для DaVinci

Сейчас профиль: `1` browse, `2` start over, `3` snippets, `4` text, `5` hide — уже Leo-форма. Разница:

- Leo не даёт точечно править имя/возраст/город с этого экрана. DaVinci в коде ещё тянет per-field edit (`name/year/gender/bio/loc/snippets`) через другой путь.
- Leo «текст» = одно био. DaVinci «текст» = био, а сниппеты — отдельный пункт. Это правильно оставить: сниппет у нас главный контент, как фото у Leo.
- «Заполнить заново» у Leo мгновенное. Для DaVinci стоит спросить, хотим ли confirm — у нас сниппеты больнее потерять, чем био.

## 4. Формат карточки

Одна формула, своя и чужая:

```
{имя}, {возраст}[, {город}] – {био}
```

- Это **caption к фото**, не отдельное текстовое сообщение.
- Перед своей карточкой всегда служебная строка `Так выглядит твоя анкета:`.
- Города может не быть (`Карина, 19 – …`).
- Био может отсутствовать (`Арина, 19, Самара` без тире).
- Пол на карточке не показывается.
- Несколько фото = альбом (у Дашули были превью 1/2/3).
- Перед выдачей карточки иногда мелькает служебное `✨🔍` (поиск).

Свайп-клавиатура под карточкой, не inline на сообщении.

### Для DaVinci

Наш `renderOwnCard`: сниппет → имя, возраст, пол, языки, город, био. Пол в ленте у Leo нет — у нас он display-only и уже рисуется. Главный adoption не в полях, а в **ритме**: одно сообщение = одна карточка = сразу действия. Легенда меню не должна залипать в каждое swipe-сообщение (сейчас `withMenuLegend` клеит пункты дома к карточкам профиля — у Leo легенда только на меню-экранах, в ленте её нет).

## 5. Просмотр и отклик

### Вход в ленту

- Дом / анкета → `1` (`Смотреть анкеты`).
- После confirm онбординга — лента сразу.
- Дом `3` (`Я больше не хочу никого искать`) в прогоне **тоже открыл карточку** (Арина). Либо пункт 3 сейчас не hide, либо hide сначала доигрывает очередь. Hide как отдельный экран не поймали.

### Действия в ленте

| Кнопка | Факт |
|---|---|
| `❤️` | Лайк **без подтверждения**. Сразу следующая карточка. Текста «ты лайкнул» нет. |
| `👎` | Скип без текста. Сразу следующая. |
| `🚨` | Не форма жалобы. Ведёт себя как скип: сразу следующая карточка. `/complaint` вне ленты отвечает: `Жалобу можно оставить только при просмотре анкеты`. Репорт = тихий флаг текущей. |
| `💤` | Выход из ленты. Текст: `Подождем пока кто-то увидит твою анкету`. Затем домашнее меню. Текущая карточка, скорее всего, откладывается, не скип. |

Лайк и скип **молчаливые**. Единственная обратная связь — новая карточка.

### Перебивание ленты

Между карточками бот вставляет промо (канал `@leoday`, `@Leomatchglobal`). После промо свайп-кнопки **перестают быть валидным ответом**, пока не уйдёшь через `/start`. Для DaVinci: не вставлять посторонние сообщения в swipe-state без своей клавиатуры.

### Мэтч / входящие лайки

В этой сессии взаимного мэтча и пуша «тебя лайкнули» не было. В истории чата таких сообщений тоже нет. Как отдают контакт — не зафиксировано. Не выдумывать.

## 6. Дом после ленты

`💤` →

```
Подождем пока кто-то увидит твою анкету

1. Смотреть анкеты.
2. Моя анкета.
3. Я больше не хочу никого искать.
***
4. …
```

Дом — не своя карточка, а короткое «ждём» + меню. Свою карточку показывают только в «Моя анкета» / `/start`.

`/language` после выбора языка тоже возвращает на дом (не на анкету).

## 7. Что брать в DaVinci

Брать механику, не dating-содержанку.

1. **Экран = либо меню с легендой, либо карточка с действиями.** В ленте не дублировать `1. Browse 2. …`.
2. **Лента: одно сообщение → сразу ❤️ / 👎 / 💤.** Лайк и скип без лишнего текста.
3. **`💤` = выйти в дом, не скип и не hide.** Сейчас у нас так и задумано (`swipeSleep`).
4. **Превью своей анкеты = ровно feed-карточка + «всё верно?».** Сейчас превью онбординга ближе к этому.
5. **После confirm — сразу лента**, не ещё один дом. Быстрее до первого свайпа.
6. **Точечный edit только главного контента** (у них фото+био, у нас сниппеты+био). Остальное — «заново».
7. **`/start` = своя анкета**, не абстрактный дом. Дом появляется после `💤`.
8. **Репорт только из ленты**, одной кнопкой, без отдельной формы. У нас репорта нет (P1) — если делать, делать как `🚨`, не как команду с дома.

Не брать:

- фото/видео как главный контент ленты (это идентичность Leo, у нас код);
- «кого показывать» как dating-фильтр;
- промо между карточками;
- обязательное био, если хотим низкий порог;
- перезапись профиля без предупреждения, пока есть сниппеты.

---

## 8. Не проверено

- hide (`Я больше не хочу никого искать`) как отдельный стейт;
- `Изменить анкету` на превью;
- валидация возраста / 18+ / чужой картинки / слишком длинного био;
- видео 15 сек;
- 2-е и 3-е фото, листание альбома;
- взаимный лайк и reveal контакта;
- входящий лайк / дайджест;
- что делает дом-`3` на самом деле.

Прогон менял живой профиль аккаунта (возраст 19, пол парень, показ девушек, город Самара, имя Саша, био как было, 1 фото).
