Волна 1 (reply-клавиатуры, цифры + легенда, свайп `❤️👎💤`, `last_card_*`, пауза) уже в master. Этот план — вторая волна по фактам живого Leo, не пиксельный клон.

## 1. Постановка задачи

Оболочка уже похожа на Leo по кнопкам. Расходится ритм:

- `/start` и `💤` оба показывают свою карточку;
- после онбординга пользователь снова видит себя, а не первую анкету;
- Лайки и Мэтчи сидят на доме, hide — в профиле. У Leo наоборот: дом = смотреть / анкета / скрыть.

Нужно совпасть по **куда ведёт каждый вход**, не меняя свайп кода и мэтч.

## 2. Текущее поведение

| Поверхность | Сейчас |
|---|---|
| `/start` готовый | `replyHome` → своя карточка + легенда дома + `1 2 3 4` |
| После confirm | та же своя карточка + дом |
| `💤` | снова `replyHome` (своя карточка) |
| Дом | 1 смотреть / 2 анкета / 3 лайки / 4 мэтчи |
| Профиль | карточка + 1 смотреть / 2 заново / 3 сниппеты / 4 текст / 5 скрыть |
| Лента | карточка без легенды + `❤️👎💤`. Лайк/скип молчаливые |
| Пустая лента / лайки | текст + легенда дома |
| Пауза | `is_active=0`, клавиатура `1` = смотреть (resume) |
| Заново | сразу `clearOnboardingFields` + онбординг, без confirm |
| `/likes` | нет; инбокс только с дома или inline дайджеста |
| `/matches` | есть |

---

## 3. Целевое поведение

1. Готовый `/start` и пункт «Моя анкета» → своя карточка + меню профиля.
2. Confirm онбординга → сразу первая карточка ленты + свайп-клавиатура.
3. `💤` и пустая лента → одно короткое «подождём» + дом без карточки.
4. Дом: смотреть / моя анкета / скрыть. Кнопки `1 2 3`.
5. Лайки и мэтчи — пункты 5–6 профиля и slash (`/likes`, `/matches`).
6. Легенда остаётся footer'ом на меню-экранах. В ленте легенды нет.
7. «Заполнить заново» — сразу, без confirm (уже так).
8. Фото в ленте, `🚨`, dating-фильтры, чат в боте — не появляются.

## 8. Референс ритма (канон этой волны)

Не клонировать продукт. Клонировать эти переходы:

| Вход | Leo | Мы |
|---|---|---|
| `/start` готовый | своя анкета + меню 1–5 | своя анкета + меню 1–6 (D1) |
| После confirm | сразу лента | сразу лента |
| `💤` | «Подождем пока кто-то увидит твою анкету» + дом 1–3 | тот же смысл, нейтральный копирайт + дом 1–3 |
| Дом `1` | лента | лента |
| Дом `2` | анкета | анкета |
| Дом `3` | скрыть (в прогоне не подтвердили отдельный стейт) | наш уже существующий pause через `is_active` |
| Лента | `❤️👎💤` (+ `🚨` не берём) | как сейчас |

Дом — не карточка. Карточку показывают только «Моя анкета» / `/start` / превью онбординга.

## 10. UX-состояния

- **Онбординг.** Те же шаги. После confirm — `replyNextFeedCard`, не дом. `/cancel` как сейчас.
- **Анкета (`/start`, дом `2`, `/profile`).** Своя карточка + footer-легенда профиля + `1–6`.
- **Дом (`💤`, пустая лента, пустые лайки, список мэтчей).** Короткий текст + footer-легенда дома + `1 2 3`. Без своей карточки.
- **Лента / инбокс.** Карточка + свайп-клавиатура. Легенды нет.
- **Пауза.** Как сейчас: «анкета скрыта» + `1` = смотреть (resume через `handleFeedCommand`).
- **Мэтч.** Короткий текст + ссылка + клавиатура дома (теперь 1–3).
- **Дайджест.** Inline «кто лайкнул» остаётся вторым входом в инбокс.

## 11. Потоки данных / state mapping

### 11.1 Клавиатуры и цифры

```
home:    1 browse, 2 profile, 3 pause
profile: 1 browse, 2 restart, 3 snippets, 4 bio, 5 likes, 6 matches
feed/inbox: ❤️ like, 👎 skip, 💤 sleep → home
paused:  1 browse (resume)
```

Физические кнопки меню — цифры. Свайп — эмодзи. Легенда только на home / profile / paused.

`isReservedInput` и разбор `^[1-6]$`. Старые текстовые alias в `exactActionMap` не чистим.

### 11.2 browse_mode

| Событие | mode | last_card |
|---|---|---|
| `/start`, `/profile`, дом `2` | `profile` | `null` |
| `💤`, empty, мэтч, `/matches` | `home` | `null` |
| карточка ленты | `feed` | id кандидата |
| карточка инбокса | `inbox` | id лайкнувшего |
| hide | `paused` | `null` |

### 11.3 Команды

| Команда | Куда |
|---|---|
| `/start` готовый | анкета (не дом) |
| `/start` онбординг | как сейчас |
| `/start` на паузе | paused-экран |
| `/profile` | анкета |
| `/feed` | лента (+ resume, как сейчас) |
| `/likes` | инбокс (новый алиас) |
| `/matches` | список мэтчей |
| `/cancel` | выход из диалога → анкета, если профиль готов; иначе как сейчас |
| `/filters` `/language` `/delete` | заглушка + дом-клавиатура |

`setMyCommands`: добавить likes, остальные не убирать.

### 11.4 Текст vs conversations

Порядок middleware не менять. `handleMenuText` по-прежнему после conversations и только если профиль готов.

Цифра `3` на доме = hide, не запись в поле. Внутри `wait()` имени/био — `isReservedInput` режет `1–6` и эмодзи свайпа.

## 12. Шаги реализации

1. Словари: `homeWait`, `menuHide`, `profileLikes` (`5. Лайки` / `5. Likes`), `profileMatches` (`6. Мэтчи` / `6. Matches`), `cmdLikes`. `menuLikes`/`menuMatches` со старыми номерами 3/4 оставить в словаре только если на них ещё ссылается alias-карта; из легенды дома убрать.
2. `keyboards.ts`: `homeKeyboard` → `1 2 3`; `profileKeyboard` → два ряда `1 2 3` / `4 5 6`; обновить `menuLegend`, `DIGITS`, `isReservedInput`, `looksLikeOtherLocaleMenu` (диапазон до 6).
3. `screens.ts`: `replyHome` больше не зовёт `ownCardMessage`. Текст `homeWait` + легенда дома + `homeKeyboard`. `/start` снаружи зовёт `replyProfileScreen`.
4. `bot.ts`: `/start` готовый → `replyProfileScreen`; `bot.command("likes", …)`; hide диспатчится с `browse_mode=home`.
5. `onboarding.ts`: после `completeProfile` (+ username warn) показать первую карточку ленты, не дом. Писать `browse_mode=feed` и `last_card_*` тем же путём, что `sendCard`.
6. `feed.ts` / `match.ts`: не менять правила свайпа/мэтча. `💤` и empty сами получат новый дом.
7. `scripts/set-webhook.ts`: команда `likes`.
8. `pnpm typecheck`. Ручной проход в Telegram (без деплоя, пока не попросят).

## 13. Проверка

- Новый пользователь: confirm → сразу свайп, без своей карточки посередине.
- `/start` после регистрации → своя анкета, не «подождём».
- `💤` → короткий дом, своей карточки нет.
- С дома `3` скрывает анкету. С профиля hide больше нет.
- Профиль `5` / `6` открывают лайки / мэтчи. `/likes` и `/matches` работают.
- Лайк / скип / мэтч / pending-username / дайджест 1/24ч — те же правила.
- В середине имени цифра `3` или `6` не записывается.
- Пустая лента не тупик: дом с тремя кнопками.
- Старый inline Like в истории может ещё нажаться — принимаем.
- `pnpm typecheck`.

Автотесты не пишем.

## 14. Риски и краевые случаи

| Риск | Обработка |
|---|---|
| Старая дом-клавиатура `1 2 3 4` | новое меню уходит с каждым экраном; `4` на доме → «нажми кнопку внизу» |
| 6 кнопок в один ряд на узком экране | два ряда |
| Hide-копирайт vs PRD | D2, нейтральная фраза |
| `/cancel` после edit вёл на дом-карточку | вести на анкету (`replyProfileScreen`), чтобы ритм `/start` не ломался |
| Список мэтчей с новой дом-клавиатурой | ок: после списка можно смотреть / открыть анкету / скрыться |
| Гонки webhook like/match | не трогаем |
| Scope creep в репорт/фильтры/💌 | стоп |
