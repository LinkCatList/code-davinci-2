## Цель

Пользователь с готовым профилем открывает `/feed` (и сразу после confirm онбординга) и свайпает: 👍 / 👎. Пустая лента — отдельное сообщение.

## Scope

- Выборка кандидатов по §10.3 (не я, active, `state IS NULL`, не лайкнут/скипнут).
- Haversine в коде; `max_dist_km` / `lang_filter` учитывать, если заданы (колонки уже есть). Пока оба NULL — глобальная лента.
- Карточка: HTML, первый сниппет + `language-*`, имя, возраст, языки, дистанция или город, био. Без фото.
- Like/skip: insert + `ON CONFLICT`/уже есть → тихо; событие `like`/`skip` только при новой строке; следующая карточка.
- После confirm онбординга: предупреждение про username (если нужно) → первая карточка ленты (или empty), не своя карточка.
- Гейт: `state !== null` → закончи онбординг.

## Non-goals

- `/filters` UI (срез 05)
- мэтч / reveal / дайджест (M4)
- сиды (M5)
- деплой, тесты, миграции

## Acceptance

- Два готовых профиля: каждый видит другого в `/feed`, like/skip пишет строку и событие, повторный тап не дублирует.
- После своего like/skip — следующая карточка или empty.
- Незавершённый профиль не видит ленту.
- Confirm онбординга сразу показывает кандидата или empty.
- `pnpm typecheck` чистый.
