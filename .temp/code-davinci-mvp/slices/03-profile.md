# Срез 03 — `/profile` edit

**Дата:** 2026-08-14  
**Родитель:** [../deep-plan.md](../deep-plan.md) (§10.7, M2 шаг 3)  
**Статус:** реализован, деплой не делали  
**Решения пользователя:** убрать 18+; био и локацию можно менять позже (в `/profile`)

---

## Цель

Завершённый пользователь видит `/profile` (своя HTML-карточка + кнопки) и меняет поля. 18+ нигде не гейтит.

## Scope

- `/profile`: карточка + edit name / year / gender / bio / location / photo / snippets.
- Год: 4 цифры, `currentYear-120…currentYear`. Без hard-stop 18+ (убрать и из онбординга).
- Био и локация: те же правила, что в онбординге, включая Skip/очистку.
- Сниппеты: 1–3; нельзя удалить последний; добавить, если меньше 3.
- `/cancel` выходит из onboarding или edit; гейт «закончи профиль» по `state !== null`.
- Storage version → 2 (изменился `askYear` / cancel).

## Non-goals

- `/feed`, `/language`, `/delete`, matches, деплой, тесты, миграции.

## Acceptance

- `/profile` после confirm показывает карточку и кнопки.
- Правка имени/года/пола/био/локации/фото/сниппета пишется в D1 и карточка обновляется.
- Год 2015 принимается.
- Последний сниппет не удаляется.
- `/profile` в онбординге → «закончи профиль».
- `pnpm typecheck` чистый.
